# mobile_sdk_api_auto
企业级分层接口自动化测试框架，适配手机相册、相机、浏览器移动端SDK后台接口全量回归

## 技术栈
Python3 + Requests + Pytest + YAML数据驱动 + Allure可视化报告 + MD5接口签名
依赖：pytest、requests、pyyaml、allure-pytest、失败重跑插件

## 分层架构说明
1. common：底层工具封装（请求、日志、yaml读写、全局登录夹具）
2. config：多环境配置文件，支持test/pre/prod一键切换环境
3. data：YAML用例层，测试参数与代码完全解耦，业务人员可改参数不用改代码
4. testcases：测试用例层，按相册/相机/浏览器分模块，只做调用和断言
5. report：自动生成运行日志、Allure测试报告

## 核心企业级亮点
1. Session会话保持，全局token自动登录、过期自动刷新重试，无需手动维护鉴权
2. 适配后端MD5签名校验，还原真实线上接口调用规则
3. pytest用例依赖，实现「创建相册→上传图片→删除图片」完整业务链路执行
4. 正向+异常全覆盖：空参数、超长入参、越权访问、幂等重复操作
5. 失败用例自动重跑，全流程日志落地，方便排查报错
6. 完全贴合日常本职测试业务：相册、相机、手机浏览器三大模块

## 覆盖业务模块
相册：文件夹增删、图片上传/批量删除、权限越权校验
相机：分辨率/帧率配置、水印开关、非法参数拦截
浏览器：网页收藏新增、缓存清理、入参合法性校验

## 运行步骤
1. 安装依赖：pip install -r requirements.txt
2. 修改config/env.yaml内环境、账号、密钥（本地修改，仓库仅模板）
3. 一键运行：python run.py
4. 打开report/allure_html/index.html查看可视化报告
